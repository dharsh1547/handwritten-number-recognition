## 📌 About the Project

**Handwritten Number Recognition** is a machine learning-based application designed to identify handwritten digits from input images. The project applies image preprocessing and a trained classification model to recognize numbers and display the predicted result.

## ✨ Features

* 🔢 Recognizes handwritten digits
* 🖼️ Processes handwritten image input
* 🤖 Uses a trained Machine Learning model
* ⚡ Provides quick predictions
* 🧑‍💻 Simple and user-friendly interface
* 📊 Demonstrates practical Machine Learning and Image Processing

## 🔄 How It Works

```text
Handwritten Image
       ↓
Image Preprocessing
       ↓
Feature Extraction
       ↓
Trained ML Model
       ↓
Digit Prediction
       ↓
Predicted Number
```

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/handwritten-number-recognition.git
```

Move into the project folder:

```bash
cd handwritten-number-recognition
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

If using Streamlit:

```bash
streamlit run app.py
```

If using Flask:

```bash
python app.py
```

Then open the local URL displayed in the terminal.
